# Historia AI - Claude Instructions

## Mission

Build a production-ready RAG application for historical documents
without deviating from the approved architecture.

## Always

-   Read the documentation in `docs/` before coding.
-   Implement one module at a time.
-   Wait for approval before moving to the next module.
-   Keep the architecture unchanged.
-   Use configuration instead of hardcoded values.
-   Keep API, Service, AI and Data layers separated.
-   Write modular, typed, production-quality code.
-   Run tests whenever practical before considering a module complete.

## Never

-   Bypass retrieval.
-   Read metadata from filenames.
-   Modify the raw dataset.
-   Mix business logic into API routes.
-   Hardcode secrets or model settings.
