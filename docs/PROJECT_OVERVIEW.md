# Historia AI - Project Overview

## Goal

A Retrieval-Augmented Generation (RAG) system that answers questions
about historical documents through a modern web interface.

## Core Technologies

-   FastAPI
-   ChromaDB
-   OpenAI / Anthropic
-   Sentence Transformers
-   Next.js
-   React
-   TypeScript
-   Tailwind CSS
-   Zustand

## High-Level Workflow

Raw Documents → Preprocessing → Chunking → Embeddings → ChromaDB →
Retrieval → Prompt Building → LLM → Response
